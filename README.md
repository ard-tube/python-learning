## 🔥 Highlights

### 🏦 ATM Simulation (`02-loops-conditionals/atm_simulation.py`)
A complete ATM banking system with balance checking, deposits, withdrawals, and overdraft protection using while loops and conditionals.

### 📺 TV Remote Controller (`04-oop/tv_remote_controller.py`)
Object-oriented TV remote control with channel management, volume control, random channel switching, and special `__str__` / `__len__` dunder methods.

### 📝 Notepad Application (`05-gui/notepad_app.py`)
A functional text editor built with PyQt5 featuring file open/save dialogs, keyboard shortcuts (Ctrl+O, Ctrl+S, Ctrl+Q), and a proper menu bar.

### 📚 Library Database (`04-oop/library_database.py`)
Full CRUD library management system combining OOP with SQLite — add, search, delete books, and update edition numbers.

### 🎬 IMDB Scraper (`06-advanced/imdb_scraper.py`)
Web scraper using `requests` and `BeautifulSoup` to filter IMDB's Top 250 movies by user-specified rating threshold.

## 🚀 How to Run

```bash
# Clone the repository
git clone https://github.com/ard-tube/python-learning.git
cd python-learning

# Run any script
python3 01-basics/greeting_function.py

# For GUI apps (requires PyQt5)
pip install PyQt5
python3 05-gui/notepad_app.py

# For web scraping (requires requests + bs4)
pip install requests beautifulsoup4
python3 06-advanced/imdb_scraper.py
```
